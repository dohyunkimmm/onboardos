# ONBOARD·OS Live Experience Walkthrough

채용 담당자와 리뷰어가 **현재 서비스**의 핵심 기능을 짧게 살펴볼 수 있는 안내입니다. 동영상 대신 실제 프로토타입에서 직접 시연하는 경로만 제공합니다.

[서비스 직접 체험](https://onboardos-rho.vercel.app/) · [관리자 체험](https://onboardos-rho.vercel.app/?review=1) · [설계 사례](https://app.notion.com/p/08d21460c934838cb66601b681e85d8c)

## 약 2–3분 직접 체험

### 1. 직무 선택 및 AI 추천 — 약 30초

1. **Google SSO로 시작하기**는 실제 인증이 아닌 체험용 로그인입니다.
2. 경영지원·총무 등 직무를 선택하고 전사 공통 도구와 직무별 도구를 확인합니다.
3. 등록된 도구의 필수·선택·준비 상태를 살펴봅니다.
4. ‘AI 추천’ 버튼을 누르면 직군 기본 추천 3개가 간단히 나타납니다. 필요한 경우에만 업무 설명을 짧게 입력해 ‘추천 받기’를 누릅니다. Gemini 요청은 서버 설정에 따라 이용할 수 있고, 신청은 사용자가 직접 확인해야 합니다.

### 2. 신청 → 관리자 검토 → 지급 완료 — 약 60초

1. Microsoft Office 등 신청 가능한 도구에서 **신청하기**를 선택합니다.
2. 신청 목적·사용 기간·필요한 권한을 확인하고 제출합니다.
3. **신청현황**에서 체험용 신청번호와 처리 단계를 확인합니다.
4. [관리자 체험](https://onboardos-rho.vercel.app/?review=1)에서 해당 신청의 검토·승인·지급 완료를 처리합니다.
5. 직원 화면으로 돌아와 동일 신청의 지급 완료 상태를 확인합니다.

### 3. 반려·재신청과 예외 처리 — 약 40초

1. 다른 요청을 반려하고 반려 사유를 확인합니다.
2. 보완 내용을 입력해 같은 요청을 다시 제출합니다.
3. 목록 외 도구나 직무 정보 누락 상황에서 별도 담당자 확인 흐름을 살펴봅니다.
4. 직무를 바꾸었다 돌아와도 직무별 신청 상태가 유지되는지 확인합니다.

## 현재 프로토타입의 범위

- 신규 입사자를 위한 **4개 직무**의 업무 도구 카탈로그를 체험합니다. **공통 5개 + 직무별 38개 = 총 43개**를 기준으로 신청·승인·지급 흐름을 확인합니다.
- 실제 Google 조직 인증, 회사 승인 시스템, Jira Service Management, SaaS 계정·라이선스 발급은 연결되지 않은 모의 절차입니다.
- AI 추천 기능만 서버에 설정한 경우 외부 Gemini API를 사용할 수 있습니다. 실사용 직원 정보나 회사 기밀을 입력하지 마세요.
- SLA 표시는 시연용 예상 처리 일정입니다. 문의량 감소·업무 시간 절감 등 실제 도입 효과를 측정한 것은 아닙니다.
