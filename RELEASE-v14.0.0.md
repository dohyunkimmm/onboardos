# ONBOARD·OS v14.0.0

## Scope

v14.0.0 formalizes the Operational Command Center post-login design already validated on main while preserving the P6 business-flow freeze. No JavaScript business logic, catalog data, request-state machine, role-isolation behavior, request semantics, or login baseline is changed by this release promotion.

## Experience changes

- Operational command-header composition with clearer identity and role hierarchy
- Five-step progress rail with stronger current-task emphasis
- Full-width filter command shelf connecting overview and content
- Work-zone section surfaces with consistent scanning rhythm
- Card status rails and stable CTA action lanes for faster state recognition
- Cohesive request modal and admin drawer execution surfaces
- Mobile-first task prioritization while preserving grid, touch-target, and no-overflow contracts
- Focus-visible, reduced-motion, forced-colors, and existing accessibility contracts retained

## Release integrity

The release is created only for an exact Production-verified commit with a successful main E2E run. Required evidence assets and the version-aligned 36-second Production Demo are attached to the same immutable GitHub Release. Production source integrity and Desktop Chromium + iPhone WebKit smoke remain mandatory release gates.
