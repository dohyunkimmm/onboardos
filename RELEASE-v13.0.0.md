# ONBOARD·OS v13.0.0

## Scope

v13.0.0 formalizes the product-grade post-login visual system already validated in Production while preserving the P6 business-flow freeze. No JavaScript business logic, catalog data, request-state machine, role-isolation behavior, or login baseline is changed by this release promotion.

## Experience changes

- Product workspace composition with stronger identity and role-selection hierarchy
- Operational five-step progress rail with clearer current-state emphasis
- Full-width filter command surface and more coherent license-group sections
- Denser card, semantic state, SLA, and CTA hierarchy for faster scanning
- Unified request modal and admin drawer execution surfaces
- Responsive/mobile ergonomics while preserving verified density and touch contracts
- Focus-within, reduced-motion, forced-colors, and existing accessibility contracts retained

## Release integrity

The release is created only for an exact Production-verified commit with a successful main E2E run. Required evidence assets and the version-aligned 36-second Production Demo are attached to the same immutable GitHub Release. Production source integrity and Desktop Chromium + iPhone WebKit smoke remain mandatory release gates.
