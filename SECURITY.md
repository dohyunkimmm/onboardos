# Security boundary

ONBOARD·OS is a browser-based portfolio prototype. v7.0.0 validates the security controls that are meaningful for this scope: CSP and response-header configuration, analytics payload allowlisting, URL/storage/console privacy boundaries, telemetry failure containment, and unsafe DOM sink checks. It does not claim production identity, authorization, secret-management, backend, or SaaS API security because those systems are intentionally not implemented in this prototype.
